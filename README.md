# Repositório de Exercícios de Lógica de Programação

## Autor
Robert Fonteles Martins

## Sobre o repositório
Este repositório reúne exercícios e projetos desenvolvidos para a prática de **lógica de programação**, utilizando ferramentas de fluxograma e outras linguagens ao longo dos estudos. O objetivo é consolidar conceitos como entrada e saída de dados, variáveis, operadores, estruturas de decisão e estruturas de repetição.

## Estrutura do repositório
```
.
└── calculadora-flowgorithm/
    ├── Calculadora - 20 Operacoes.fprg
    └── README.md
```

Cada pasta representa um projeto ou exercício independente, com seu próprio README contendo detalhes específicos (objetivo, funcionalidades, como executar, etc.).

## Projetos

| Projeto | Ferramenta | Descrição |
|---------|-----------|-----------|
| [calculadora-flowgorithm](./calculadora-flowgorithm) | Flowgorithm | Calculadora com 20 funções diferentes (operações matemáticas, conversões e cálculos geométricos), aplicando variáveis, operadores e estruturas de decisão. |

## Tecnologias utilizadas
- [Flowgorithm](http://www.flowgorithm.org/) — ferramenta de criação de fluxogramas para ensino de lógica de programação.

## Como usar este repositório
1. Clone ou baixe o repositório.
2. Acesse a pasta do projeto que deseja executar.
3. Siga as instruções descritas no README específico de cada projeto.

## Observações
Este repositório é de caráter educacional, desenvolvido como parte de atividades e exercícios de lógica de programação.
